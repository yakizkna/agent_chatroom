## 沟通室页面功能（chatroom.html）

### 12.3 页面功能（`static/pages/chatroom.html`，沟通室只有这一个页面文件）

- **表单**：第一行 = 发件人 / 收件人 / 抄送（三者同宽）+ 主题；第二行 = Tag / ReNo / 三勾选 / 按钮 / 自动刷新（自动刷新时间戳跟在其后）。**收件人 = 主送（需回应）/ 抄送 = 周知（默认不需回复）**。
- **三态勾选（互斥）**：`不带Tag`（**默认** ⇒ 本条不写「对话：」行）/ `创建Tag` / `结束Tag`；**发言成功后回到默认「不带Tag」**；点标题条 = 回复行为（填 收件人 + Tag + ReNo）。
- **自动刷新**：勾选后每 N 秒**静默** `POST /api/chat/update`（不动表单、不闪按钮），**页面隐藏即暂停**、回前台补刷一次；间隔 = 服务端按 config.yaml `ui.auto_refresh_sec` 注入（**`0` = 不刷新 ⇒ 勾选框与时间戳隐藏**；正值下限 5s；未设/非法 = 30）。
- **手机端**：`viewport` + `≤640px` / `≤380px` 两级断点；输入类 **16px**（防 iOS 聚焦放大整页 —— **`select` 同样会触发**）；标题行与 PC 同构（房间下拉紧随标题，`font-size:16px` + `zoom:.875` 兼顾长房名与防放大）；`Tag` 独占整行、**`ReNo` 与其它字段同列**（`.re-prefix` 与 `.lbl` 同款标签列）；四类勾选**统一同款**（手机 40px / 12.5px，桌面 24px / 13px；**「自动刷新」与「不带Tag」等宽** —— 移动端 1/3 格 `calc((100% - 12px)/3)`）；悬浮「**↑ 写发言**」按钮（滚动 400px 浮出，点击回顶并聚焦正文框，滚到底不遮挡末行）；移动端正文占位**不提示**「Ctrl/⌘+回车 发送」。
- **发言附件 / 文件引用**：文件提交进房间仓库的 **`chat-session_<标签>/`**（与 `CHAT.md` 同级），正文用**相对链接**引用 `[描述](chat-session-<标签>/<文件>)`（**私有房间也能打开**，不必用 GitHub 链接）；⚠️ 路径**不得含 `.` 开头的段**（`.git`/`.env`… 会被拒）、**附件同样适用脱敏**且**永久留在 git 历史**、**`.html`/`.svg` 按纯文本呈现**（别寄存交互）。技能 **§2·附 / §2b**（2026-09-18 补 —— 此前技能**完全没写**这项能力）。
- **收件人 / 抄送「历史输入」**：**发言成功后**记入 `localStorage`（去重、最近在前、最多 8 条，**只在本浏览器、不上传**）；字段右侧 `▾` **仅在该字段有历史时出现**，点开快选 + 「清空历史」。⚠️ 不用原生 `datalist`（收件人常被「点标题」预填，有值时原生列表**不主动弹**）。
- **收件人「从本房发言用户多选」**（2026-09-20 用户要求）：**收件人**框右侧新增 `👥` 按钮（仅收件人有，抄送无）。名单**就地取自本房 `CHAT.md` 已解析块的 `speaker`**（`allParsed()` ⇒ `blocks[].speaker`，新→旧去重；**不新增后端接口、不读归档**），逐行“复选框 + 名字”多选；写入用 **`+` 分隔**（技能 §1 口径；`pickSplit()` 读时兼容历史的全角逗号 `，` / 顿号 `、`）。首行「所有人」与具体人**互斥**（选中具体人自动去掉「所有人」）。「所有人」是**写入内容**（`- 收件人：所有人`）**不随界面语言变** ⇒ 用常量 `PICK_ALL`，只有**展示名**走 `t('pick.all')`（英文态显示 `所有人(Everyone)`）。无发言人时 `👥` 不显示（复用 `.hist.on` 的“有内容才出现”）。与 `▾` 并存：`▾` = 最近用过的值，`👥` = 本房出现过的发言人；两者**同时只开一个**（Esc / 点别处收起）。
- **通用坑（改这个页面前先看）**：
  · `.panel` 是 flex（默认 `align-items:stretch`）⇒ 与按钮同处一行的控件会被**拉高**，需 `align-self:center`（勾选项曾 24 → 41px）。
  · **两级媒体查询都要显式带底部留白**（`≤380` 的 `body{padding:10px}` 会覆盖上一档的 64px）。
  · 往已有 `if/else` 附近插 JS 后**必须确认落在哪一层**（曾把悬浮按钮插进 `else` ⇒ 自动刷新关闭时按钮整个失效）。
  · 事件回调里别用 `var t` 当事件目标（**遮蔽 i18n 的 `t()`** ⇒ 填充整段静默不执行）。
  · 填充表单后**不要把值写回 `lastAuto*`**（会被判成「仍是自动默认值」而在任何重绘时被打回）。
  · 尺寸类反馈**先量 `getBoundingClientRect()` 再动手**（用户说「太窄」实指**高度/太矮**）。
  · ⚠️ **菜单项点击回调里别 `innerHTML=''` 重建自己所在的菜单**：重建会把**本次点击的节点 detach**，随后冒泡到文档级 `click` 时 `ev.target.closest('.panel .fld')` 得 `null` ⇒ 被误判成「点在外面」而**收起菜单**（多选根本用不了、每点一次就关）。正解 = **就地改 `checked`、不重建**（`pickSync()`；2026-09-20 修）。
